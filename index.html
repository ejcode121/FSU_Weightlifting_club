Trip basics

🏠 Airbnb options near the venue

Venue: Greater Richmond Convention Center. Add each listing's price breakdown and how far it is from the venue (use Google/Apple Maps). Each one is graded A–D from distance + cost per person. We work out how many places the whole team needs. Select one to use it in the budget.

Grading settings

Price counts for the rest of the grade. Score 75+ = A, 55+ = B, 35+ = C, below = D. A listing with no distance can’t be graded.

🚐 Transportation options

Rental vans, charter bus, or flights. A red-eye home (leave the night of the meet) is only allowed where a professional driver or a flight does the overnight leg — vans default to staying the extra night.
